# وب‌سایت مودا (MODA)

نسخه فارسی و راست‌چین فروشگاه نمایشی پوشاک مودا، همراه با داشبورد داده‌کاوی.

## اجرا در ویندوز
1. این پوشه را استخراج کنید.
2. در پوشه‌ای که فایل `index.html` قرار دارد، ترمینال را باز کنید.
3. دستور `python -m http.server 8000` را اجرا کنید.
4. در مرورگر آدرس `http://localhost:8000` را باز کنید.

## بخش‌ها
- فروشگاه و فهرست محصولات نمونه
- جست‌وجو، دسته‌بندی و مرتب‌سازی
- سبد خرید و ثبت سفارش نمایشی (بدون پرداخت واقعی)
- داشبورد داده‌کاوی متصل به خروجی‌های پروژه (پاک‌سازی، K-Means و Apriori)

داده‌ها آموزشی و ساختگی هستند و نتایج، ادعایی درباره بازار واقعی نیستند.
